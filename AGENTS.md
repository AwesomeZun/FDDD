# Repository conventions

- English is the default language for this personal repository: the main README, new public documentation, showreels, and other presentation assets.
- Keep Korean translations as explicitly labeled alternatives. `README.md` is the English entry point; `README.ko.md` is the Korean translation. Preserve the existing `README.en.md` entry point.
- Preserve existing user-facing deliverables before editing, and create successors using full `vMAJOR.MINOR.PATCH` versions. Keep canonical entry points aligned with the current version when requested.
- Preserve scientific distinctions between measured connectivity, computed spikes and docking results, authored behavior, and motion graphics. Do not turn a demonstration into a claim of validated drug efficacy.
